本次加入了「重生」机制 —— 每个身份倒下一次之后，都能换个身份接着打。

■ 新增：所有角色都可以重生一次
以前被击倒就直接结算。现在每个身份部署后都有一次重生机会：倒下后不会立刻结束，而是以另一个身份重新部署进设施，并且**当前进度全部保留** —— 行动时间、已恢复的供电、已上传的收容协议、已收容的异常、护送换来的伤害加成、战绩统计，一样都不会清零。第二次倒下才是真的结束。

■ 重生后的身份
· 常规行动
  - MTF（Nu-7）→ 保持 MTF，原地重新部署
  - 设施保安 → Nu-7 突击兵
  - 科学家 → Nu-7 收容专家
  - Class-D → 混沌分裂者
  - SCP-173 / 096 / 939 / 106 / 079 → 蛇之手
· 5K 行动
  - 科学家 → Nu-22「火箭侠」
  - 保安 → 反叛之狐
  - 其余沿用常规

■ 新增可玩身份：蛇之手
收容物被压制后，蛇之手会把你接过去。装备 MP5 + Glock-18 与轻质防弹衣，与设施内的基金会人员敌对，目标是清除他们然后撤离。
注意：重生为蛇之手之后你就是蛇之手的人了 —— 设施里的蛇之手 NPC 不会攻击你，你也不会误伤他们。混沌分裂者身份同理。

■ 5K 行动里的蛇之手
5K 没有撤离点，蛇之手的目标是把设施里的基金会人员清空。反叛之狐的复活点也做了分离处理，不会和 Nu-22 挤在同一个入口。
