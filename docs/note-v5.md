本次是一次大更新：加入了「开局随机角色」的回合制玩法、可操控收容物、设施幸存人员、掉落武器与势力增援，并做了一轮平衡调整。

■ 新增：开局随机角色（还原 RXSEND 的随机阵营机制）
进入落锤行动时会随机分配一个身份，装备、出生点、目标链全部跟着变，且不能重抽、菜单里也不透露，落地才用「你是 XXX」告诉你：
· MTF Nu-7（30%）—— 自选配装，完整任务链
· 设施保安（25%）—— 手枪 + 轻甲，恢复供电与协议后撤离
· 科学家（25%）—— 空手，销毁档案后撤离
· Class-D（20%）—— 空手，活着走到电梯
· SCP-079（6%）—— 没有身体，用摄像头、AP、门、停电与特斯拉门作战
· SCP-173 / 096 / 939 / 106（各 6%/6%/4%/4%）—— 直接附身本体，各有各的玩法

■ 新增：撤离不是终点 —— 第二身份
非 MTF 角色撤离后不会结束游戏，而是被重新部署：Class-D 转为混沌分裂者、科学家转为 Nu-7 收容专家、保安转为 Nu-7 突击兵，换一套装备和目标继续打。

■ 新增：可操控的实体收容物
· SCP-173 —— 只要有人看着你就一步也动不了，NPC 也会眨眼，那是你唯一的窗口
· SCP-096 —— 平时温顺，有人看见你的脸就暴走，速度翻五倍
· SCP-939 —— 没有眼睛，屏幕上会标出附近会出声的人
· SCP-106 —— 穿墙

■ 新增：设施幸存人员
D 级人员（放他跑掉会让混沌分裂者提前突入）、研究员与设施保安（护送到入口大堂撤离可换来对异常/对敌对的伤害加成，可叠加）。

■ 新增：掉落武器
设施里会散落 UMP-45、MP7 与 Glock-17（Glock-17 为半自动），只有 Class-D / 科学家 / 设施保安可以拾取使用。

■ 新增：势力增援
混沌分裂者、蛇之手与 MTF 队友在首次部署后每 30 秒补充一次（各有场上上限），HUD 会显示增援倒计时。

■ 新增：MTF 不是一开始就在设施里的
Nu-7 火力组在开局 1 分钟后才进场，前 60 秒设施里只有你自己。

■ 平衡调整
· SCP-939 一口伤害 58 → 32，现在谁都咬不死一口；3114 / 682 / 076 / 966 的伤害也一并下调，173 降速。
· 人类阵营加强：玩家 115 HP、护甲减伤提升至 24/36/48%、MTF 队友 170 HP。

■ 修复
· 混沌分裂者无法攻击科学家与保安
· 结算面板不分身份，一律显示 MTF 的成绩单
· 掉落武器没有枪模（捡到手上一把看不见的枪）
· SCP-096 温顺时站在原地不动，现在会自行游荡
· 玩家无法射击混沌分裂者与蛇之手
