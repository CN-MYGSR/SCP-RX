本次把剩下四只收容物也做成了可操控的，并小幅上调了抽到收容物的概率。

■ 新增可操控收容物：SCP-049 / 3114 / 076-2 / 682
之前只有 173 / 096 / 939 / 106 / 079 可以附身。现在补齐了另外四只，各有各的手感：
· SCP-049「瘟疫医生」—— 走得很慢，碰到即死；会**把附近的尸体拉起来**变成 SCP-049-2 替你打人
· SCP-3114「骸骨」—— 全场地速最快，连击也最快，代价是血薄
· SCP-076-2「亚伯」—— 近战伤害高，而且**被打倒后还会自己站起来一次**
· SCP-682「不灭孽蜥」—— 血厚、伤害高，还会**自动朝人喷酸液**（落点溅射，一口 70）

注意：076-2 / 682 / 3114 **不是"碰即死"**，它们按伤害结算（34 / 52 / 26），只有 049 保持碰即死。

■ 小幅上调收容物概率
可操控收容物的抽取权重整体上调，收容物总占比从约 20.6% 提到约 29%。
