本次把「复活」从一次性改成无限次。

■ 复活改为无限次
以前每个身份只有一次重生机会，第二次倒下就结算。现在**倒下多少次都会重新部署**：
· 第一次倒下按身份映射换阵营（Class-D → 混沌分裂者、科学家 / 保安 → Nu-7、收容物 → 蛇之手；5K 里科学家 → Nu-22、保安 → 反叛之狐）
· 之后再倒下就保持当前身份原地复活
· 每次复活都是满血、回到该身份的出生点，本局进度（行动时间、供电、收容协议、已收容异常、护送加成、战绩统计）全部保留

■ 想结束一局怎么办
现在只有两条路会真正结束：达成目标，或者在暂停菜单里主动「放弃行动」。
「放弃行动」被特别排除在复活之外 —— 否则点了放弃会被立刻重新部署，永远退不出这一局。

■ 5K 里的反叛之狐
反叛之狐现在也能复活（上一版漏了这条映射），而且复活时不会再被塞回那 60 秒待命屏。
