本次修了四处平衡问题。

■ 地图：所有 NPC 都会显示
之前雷达和大地图只画了收容物、小怪和 MTF 队友 —— 设施人员（保安 / 研究员 / D 级）和两支入侵势力（混沌分裂者 / 蛇之手）根本没画。结果是不管你玩哪个阵营，地图上都找不到大多数人。
现在全部上图标：
· 雷达：D 级橙、研究员浅灰、保安蓝、CI 暗红、蛇之手绿
· 大地图：同样配色，并带「D级 / 研究员 / 保安 / CI / SH」标签

■ SCP-173：眨眼改成全体同步
以前每个 NPC 各自随机眨眼（睁 3~8 秒、闭 0.26 秒），单个 NPC 的眨眼占空比只有约 4.7%。而 173 要**所有观察者同时眨眼**才能移动 —— 两个观察者就只有 0.2%，三个是 0.01%，等于一步也走不了。
现在所有 NPC 同步眨眼：睁眼 2~3 秒 → 全体闭眼约 1 秒。173 每几秒就有一个明确的冲刺窗口（约 1 秒，够跑 9 米）。面板上会直接写出「眨眼倒计时」和「窗口还剩」，不用再靠猜。

■ SCP-096：加了击杀冷却
096 高速 + 碰即死，守在入口能来一个杀一个，对面完全没有还手窗口。
现在**造成击杀后会进入长冷却**：096 是 3.2 秒（普通攻击间隔只有 0.8 秒），其余收容物 1.8~2.6 秒。一次只能带走一个人，然后必须等。

■ 重新部署的无敌时间
被打倒重新部署后会有 **4 秒无敌**，防止刚落地就被守在出生点附近的收容物秒掉（尤其是 096）。HUD 上会显示「🛡 重新部署保护 · X.X 秒」倒计时。
