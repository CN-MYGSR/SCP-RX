本次更新加入两支敌对势力，并把 SCP-096 改成「打不死 · 只能戴头套收容」。

■ 入侵势力（仅落锤行动）
· 混沌分裂者：行动开始 5 分钟后从重收电梯厅突入，5 人小队，全员与玩家和 MTF 队友敌对，会主动接敌。
· 蛇之手：混沌分裂者入场 1 分钟后跟进，3 人小队。他们不打阵地战，目标是跑到已收容异常的收容间，把异常重新放出来。
· 放逐按威胁等级由低到高：173 → 966 → 049 → 939 → 096 → 106 → 3114 → 076 → 682。先放弱的，682 是最后一张牌。
· 每个成员到位后要停 3 秒读条才能完成放逐，这 3 秒是打断的窗口。全灭蛇之手才能止住放逐。
· 撤离条件追加「入侵势力清零」——只要还有人活着，撤离电梯就不会解锁。
· 两支势力各有专属入场音乐。

■ SCP-096 收容方式调整
· 096 现在免疫一切伤害，打不死 —— 与收容行动一致，唯一的收容方式是靠近长按 [F] 给它戴上收容头套。
· 戴上头套即计入清剿进度（不算击杀）。
· 暴走状态持续 25 秒后会自动平静，避免玩家不小心把它看暴走后陷入无法收容的死局。
